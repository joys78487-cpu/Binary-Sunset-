# Tatooine Binary Sunset

A visually stunning HTML5 canvas animation inspired by the iconic binary sunset scene from Star Wars, featuring twin suns slowly setting behind Luke Skywalker's homestead on Tatooine.


## Features

- Smooth canvas animation using `requestAnimationFrame`.
- Atmospheric sky gradient with color transitions mimicking a Tatooine sunset.
- Twin suns with glow and shadow effects.
- Foreground silhouette including:
  - Dome-shaped homestead
  - Luke Skywalker figure
  - Ground desert landscape
- Fully responsive animation (canvas size adjustable in code).
- Looping sunset for continuous effect.
